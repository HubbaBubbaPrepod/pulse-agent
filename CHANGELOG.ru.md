# История изменений

> [English version](CHANGELOG.md)

## [0.6.0] — 2026-10-25

- Добавлен необязательный runtime `wasip1`: ограниченный WASI-интерпретатор, посредники разрешённых операций, согласование поддержки и отдельное состояние. Компоненты без runtime сохраняют нативное поведение.
- Секретные поля и настройки хоста не передаются гостю; смена runtime или контракта разрешений требует повторного согласия.

- Обновлена зависимость поддержки Windows с исправлением проверки длины Unicode; сборка исходников требует Go 1.25+, релизы собираются Go 1.27.3.

- Потомки нативного модуля завершаются при таймауте, отмене и обычном выходе: группы процессов Linux / Windows Job.
- Отмена останавливает и приостановленный Windows-процесс до назначения в Job.
- Релизы собираются Go 1.27.3. Контроль процессов не является песочницей для нативного кода.

## [0.5.0] — 2026-10-18

- Добавлен `-connect-address IP:port`: прямое подключение к Monitor с сохранением Host, SNI и проверки HTTPS-сертификата. Подходит для агента на одном сервере с Monitor за публичным прокси.

- Добавлен отдельный транспорт нативных вызовов v2: проверка хешей/разрешений, отмена и постоянные квитанции без повторного выполнения ручных операций. Публичные результаты ограничены и скрывают секреты; телеметрия v1 сохранена.

### Изменено

- Полная парная документация на русском и английском: установка, возможности платформ, участие, поддержка и приватные сообщения об уязвимостях.
- Указана текущая версия отдельного Docker-модуля: v1.0.2.

## [0.4.0] — первый публичный выпуск

### Добавлено

- Независимое приложение Linux amd64/arm64 и Windows amd64 для Pulse Monitor.
- CPU/память, процессы, диски, соединения, журналы ОС и доступная GPU-телеметрия; опциональные метаданные пакетов через установленный TShark.
- Отправка отчётов по HTTPS с отдельным токеном узла, сохранение одного отчёта для повторной отправки и курсора журналов.
- Экспериментальный протокол модулей v1: скачивание проверенных SHA-256 бинарников, запуск отдельного процесса и JSON-результаты.
- Отдельный Docker-модуль pulse-module-docker, служба Linux/systemd и Windows, платформенные архивы и SHA-256 checksums.

### Примечания

- Совместимая пара первого публичного выпуска: Pulse Monitor v0.4.0 / Pulse Agent v0.4.0.
- Модули выполняются без песочницы с правами агента. GPU и журналы зависят от прав, ОС и драйвера.
- До v1.0 будущая совместимость не гарантируется; несовместимые изменения будут описаны здесь.
