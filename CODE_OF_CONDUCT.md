# Code of conduct

> [Русская версия](CODE_OF_CONDUCT.ru.md)

This applies to issues, pull requests, reviews, and other project spaces. Treat participants with respect regardless of background, identity, or experience. Give specific, constructive feedback; discuss the work without personal attacks. Harassment, threats, discrimination, sexual content directed at participants, and publishing another person's private information are unacceptable.

Maintainers may edit or remove disruptive content and restrict participation to protect the community. They should apply these expectations consistently and avoid exposing private reports.

For public moderation concerns, contact maintainers through the relevant repository thread without repeating abusive or private material. For a sensitive report, use a private contact method explicitly published on the [maintainer's GitHub profile](https://github.com/HubbaBubbaPrepod), if available. Do not post personal information to obtain a response. Software vulnerabilities belong in the [private security channel](SECURITY.md).
