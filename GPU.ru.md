# Мониторинг GPU

Русский · [English](GPU.md)

Сбор GPU поддерживает Linux и Windows, NVIDIA, AMD и Intel, встроенные и дискретные карты, а также системы с несколькими производителями. Интервал сбора — пять секунд. Формат отчёта сохранён. Доступность каждого показателя задаётся флагом `supported`. Если адаптер обнаружен, но драйвер не предоставляет показатель, поле остаётся недоступным.

В отчёт входит до 32 адаптеров согласно лимиту Monitor. Обновляйте Monitor вместе с Agent, чтобы панель принимала измеренное использование памяти при недоступной ёмкости VRAM. Опрос NVIDIA и системных источников выполняется независимо. Внешние команды имеют таймаут четыре секунды.

| Платформа / драйвер          | Источники                                                                                                                                                                                             |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Проприетарный NVIDIA         | `nvidia-smi`: загрузка, выделенная память, температура, мощность и вентилятор при поддержке драйвера. Linux дополнительно использует `pmon`; память вычислительных процессов зависит от драйвера.     |
| Linux AMD / amdgpu           | Обнаружение DRM, загрузка и VRAM через sysfs, температура и мощность из GPU hwmon, процент PWM вентилятора при наличии. Процессы — через DRM fdinfo.                                                  |
| Linux Intel i915 / xe        | Обнаружение DRM и счётчики процессов fdinfo: наносекунды занятости либо разность занятых/полных циклов. Загрузка определяется по самому занятому движку видимых клиентов с учётом количества движков. |
| Остальные Linux DRM-драйверы | Обнаружение и те же стандартные интерфейсы sysfs/fdinfo в объёме, реализованном драйвером. NVIDIA может использовать DRM при отсутствии `nvidia-smi`.                                                 |
| Windows WDDM 2+              | DXGI определяет адаптеры и 64-битный объём выделенной VRAM. Нативные счётчики PDH дают загрузку движков и использование выделенной памяти с привязкой по LUID, включая показатели процессов.          |

На Linux видимость fdinfo зависит от прав `/proc` и драйвера. Первый отсчёт накопительных счётчиков нужен для прогрева. Повторяющиеся и общие дескрипторы учитываются по устройству и ID клиента DRM. При временном уменьшении счётчика сохраняется прежний максимум. Сканирование ограничено одной секундой и 32 768 файлами. Загрузка по видимым клиентам может недооценивать недоступные агенту процессы. При наличии аппаратного счётчика загрузки используется он. В памяти процессов учитываются резидентные локальные/VRAM-регионы отдельно от системной памяти. Сумма клиентских буферов не выдаётся за полное использование памяти адаптера.

На Windows LUID связывает счётчики с конкретной картой. Английские пути `Get-Counter` и ограниченное 32 битами поле `Win32_VideoController.AdapterRAM` не используются. Датчики NVIDIA дополняют адаптер при единственном совпадении имени. При одинаковых именах нескольких NVIDIA сохраняются показатели DXGI без угадывания соответствия датчиков. Вычислительные NVIDIA, отсутствующие в DXGI, остаются видимыми через `nvidia-smi`. Отсутствующие PDH-счётчики оставляют поля недоступными. Запрос используется повторно между опросами и закрывается при остановке агента. Счётчики загрузки прогреваются на первом отсчёте. Старые WDDM-драйверы и программный адаптер Microsoft не предоставляют те же аппаратные показатели. Учёт памяти процессов GPU в Windows имеет ограничения самой ОС.

Температура, мощность и вентилятор доступны не на всех сочетаниях GPU и драйвера. Карта может предоставлять загрузку без этих датчиков. Обороты вентилятора не преобразуются в вымышленный процент. Общая системная память не обозначается как выделенная VRAM.

Агент не устанавливает драйверы, утилиты, модули ядра или новые зависимости Go. NVIDIA использует существующую утилиту драйвера. DRM/sysfs и DXGI/PDH предоставляются системой и драйвером.

`pulse-agent -check` показывает локальный список GPU и флаги доступности. Проверки с реальным оборудованием отделены тегом `integration`. Автотесты покрывают данные обеих платформ, но проверка одного ПК не подтверждает все сочетания моделей и драйверов.
